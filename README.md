### Трекер историй и желаний — Telegram-бот

Бот раз в час спрашивает:
- что вы сделали за последний час;
- с каким из героев вы хотите себя ассоциировать сейчас.

Затем бот дает рекомендацию: как двигаться дальше так, чтобы не навредить текущим планам и при этом следовать своим желаниям.

#### Быстрый старт (Windows PowerShell)
1. Установите Python 3.10+
2. Создайте и активируйте виртуальное окружение:
```
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```
3. Установите зависимости:
```
pip install -r requirements.txt
```
4. Создайте файл `.env` в корне проекта и добавьте строку с токеном бота:
```
BOT_TOKEN=ВАШ_ТОКЕН_БОТА
```
5. Запустите бота:
```
python bot.py
```

#### Команды бота
- /start — запустить и включить напоминания (по умолчанию каждые 60 минут)
- /pause — приостановить напоминания
- /resume — возобновить напоминания
- /getinterval — показать текущий интервал
- /setinterval <минуты> — установить интервал (5–1440)
- /addplan текст задачи — добавить пункт плана
- /listplans — показать активные планы
- /doneplan номер — отметить пункт плана как выполненный
- /heroes — список архетипов героев

Вы можете просто ждать напоминаний: бот спросит «Что вы сделали за последний час?», затем предложит выбрать героя и сразу пришлёт рекомендацию.

Данные хранятся локально в `data/state.json`.
